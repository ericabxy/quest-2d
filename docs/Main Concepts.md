Main Concepts
=============

Overworld traversal akin to Mystic Quest.

- Tile-aligned starting and stopping points.
- "Jump" button can leap two spaces forward except when blocked by certain terrain and objects.
  - Can jump over "treasure chests".
  - Can jump over people?
  - Can jump over one water tile.
  - Can jump over chasm (empty or air tile).
- "Fire" button can use tool to interact with space in front of player.
  - First tool is "sword" which stabs the forward tile.
  - Can push buttons and cut grass.

Non-player character interaction like Final Fantasy.

- "Jump" or "Fire" button instead talks to character in front of player.
- One or more lines of dialogue that can be advanced ("Jump") or cancelled ("Fire").

Cycle through equipped tools with "L" and "R".

- Second tool is "Bomb" or "Grenade", consumable that can destroy cracked walls and debris piles.
